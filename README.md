🍽️ Django Recipe Management System

A simple and user-friendly **Recipe Management Web Application** built using **Django**.  
This project allows users to manage recipes efficiently through a clean interface.

# Project Overview
The Django Recipe Management System helps users:
- Add new recipes
- View available recipes
- Update or delete existing recipes
- Manage recipe data easily

This project focuses on **CRUD operations**, backend logic, and frontend integration using Django.

# Features
- Clean and responsive UI
- Add, edit, and delete recipes
- Display recipes in an organized manner
- Image support for recipes
- Beginner-friendly Django project structure

# Tech Stack
- **Backend:** Python, Django  
- **Frontend:** HTML, CSS, JavaScript, Bootstrap  
- **Database:** SQLite  
- **Tools:** Git, GitHub, VS Code
